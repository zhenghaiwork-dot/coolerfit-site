    level: h2
    body: ''
    bullets:
      - Measured pad area, not outside cabinet → remeasure widest W×D×H
      - Forgot casters (add 3–6") → include floor-to-highest-point height
      - Between chart rows and sized down → always size up; drawcord takes slack
      - Side-draft cover on down-draft unit (or reverse) → match profile to intake location
      - One size for three models → one row per model in your dimension table
