  - heading: Una especificación para una flota con distintos equipos
    level: h2
    body: Los contratistas HVAC y los equipos de mantenimiento rara vez compran para un solo gabinete. Un mismo proyecto puede incluir unidades de descarga lateral, equipos de techo y enfriadores portátiles de varias marcas. La solución no es forzar una talla genérica, sino registrar cada equipo y producir el lote bajo una especificación común de tela, color, sujeción y acabado.
    bullets:
      - Asigne un ID a cada unidad o ubicación para evitar cambios durante la instalación
      - Registre ancho × fondo × alto exteriores y la cantidad requerida de cada medida
      - Añada fotos de ductos, tuberías, cajas eléctricas, ruedas y otros salientes
      - Indique exposición a sol, viento, polvo, lluvia o ambiente costero para elegir la tela

  - heading: Medidas mixtas dentro de una misma orden de compra
    level: h2
    body: Podemos agrupar distintas medidas en una sola orden siempre que cada renglón identifique el equipo, la cantidad y los detalles de ajuste. Mantener el mismo código de tela y color ayuda a uniformar la flota, mientras cada patrón conserva sus propias dimensiones, aberturas y puntos de amarre. Los patrones aprobados se guardan para facilitar reposiciones posteriores.
    bullets:
      - Una hoja de cálculo puede incluir modelo, ubicación, medidas, cantidad y notas por unidad
      - Los logotipos y colores pueden mantenerse uniformes aunque cambie el tamaño de la funda
      - Las reposiciones pueden solicitarse por ID de patrón sin reconstruir toda la especificación

  - heading: Mínimo flexible y costo real del proyecto
    level: h2
    body: Ofrecemos cantidades iniciales flexibles, pero no prometemos una sola pieza como mínimo universal. La cantidad mínima viable depende del tamaño terminado, la tela, las aberturas, la impresión y el destino. Para envíos a Estados Unidos o Europa, consolidar varias fundas suele repartir mejor la preparación y el flete internacional que comprar piezas aisladas.
    bullets:
      - Envíe el rango de cantidad esperado para comparar lote pequeño y precio por volumen
      - Combine medidas compatibles bajo una misma tela para mejorar la eficiencia del pedido
      - Separe el costo de producción del transporte, impuestos y entrega final al evaluar la oferta

  - heading: Logotipo, identificación y control de reposiciones
    level: h2
    body: Para contratistas, administradores de propiedades y equipos multisede, la impresión puede servir tanto para la marca como para identificar edificio, zona o activo. Confirme el método, el tamaño y la posición del gráfico antes de cortar el lote; después de aprobarlo, conservamos la referencia junto con el patrón para mantener consistencia en futuras compras.
    bullets:
      - Envíe arte vectorial cuando esté disponible o un PNG de alta resolución
      - Indique una posición que no interfiera con cierres, costuras ni aberturas de servicio
      - Use un código de activo impreso o una etiqueta separada cuando cada funda deba volver al mismo equipo

  - heading: Proceso de cotización y producción
    level: h2
    body: La cotización comienza con la lista de equipos, las medidas, las fotos, la cantidad, el destino y la fecha requerida. Revisamos interferencias, proponemos material y confirmamos el mínimo viable del proyecto. El plazo habitual de producción para lotes pequeños confirmados es de 10 a 14 días hábiles después de aprobar medidas, tela, aberturas y arte; este plazo no incluye transporte internacional ni entrega local. Los lotes grandes o materiales especiales se programan por separado.
    bullets:
      - 1. Envíe la tabla de equipos, fotos, cantidad y destino
      - 2. Revise la propuesta de material, patrón, logotipo, mínimo y precio
      - 3. Apruebe por escrito medidas y arte antes de iniciar producción
      - 4. Reciba el lote con sus IDs de patrón para futuras reposiciones

Una compra profesional de fundas para enfriador evaporativo debe resolver más que una medida. La meta es que cada equipo reciba el ajuste correcto y que compras pueda repetir la misma especificación, incluso cuando la flota combine modelos, tamaños y ubicaciones.
