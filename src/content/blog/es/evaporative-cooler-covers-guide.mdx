  - heading: ¿Qué problema quiere resolver?
    level: h2
    body: La mayoría de los pedidos de fundas empiezan con uno de estos casos — relacione su situación con el siguiente paso correcto.
    bullets:
      - Los cuartos se sienten más fríos tras el apagado → necesita una funda que selle los paneles de entrada (vea beneficios y preparación para invierno)
      - Óxido, moho o avispas cada primavera → vacíe y seque primero, luego cubra (lista de preparación para invierno)
      - La funda no ajusta o se vuela → tipo o talla incorrectos; vuelva a medir A×P×H exterior
      - No está seguro de para qué sirve una funda → empiece con el artículo qué es, abajo
  - heading: Tres decisiones antes de pedir
    level: h2
    body: Si acierta en estas, desaparecen la mayoría de las devoluciones.
    bullets:
      - Tipo de enfriador — entrada lateral, superior, azotea o ventana (el perfil debe coincidir con las entradas)
      - Medida exterior — A×P×H más amplio incluyendo ruedas; entre filas de la tabla, elija la talla mayor
      - Tela — 600D PU para inviernos secos; vinilo si la lluvia se acumula sobre la unidad; malla nunca para invierno
