    level: h2
    body: Pad width is smaller than the cabinet. Casters add 3–6 inches stock charts ignore. Averaging three models into one size fits none of them. Custom only works if dimensions reflect the real outside outline.
  - heading: 'Solution: Measure Outside at Widest Points'
    level: h2
    body: ''
    bullets:
      - Width — widest face, including side handles or panel bumps
      - Depth — include hose ports or panels that stick out past the frame
      - Height — floor to highest point, casters included
      - One spreadsheet row per model number — never one "average" row for a mixed fleet

    level: h2
